Architecture overview

Dispatch

A standalone, self-hosted daily editorial brief generator for software projects. Watches a configurable registry of repositories, synthesizes a daily report with audio narration, and publishes weekly podcasts.

System architecture

A Vite SPA frontend and a FastAPI backend, joined by a Caddy reverse proxy and gated by whatever perimeter the operator chooses. The backend is self-contained: SQLite for state, an in-process scheduler, and swappable adapters for storage, AI synthesis, and text-to-speech.

Daily pipeline

A single scheduler tick walks four stages: ingest upstream activity, synthesize a brief with the configured AI provider, narrate it via TTS, and publish a snapshot plus an audio file to the storage backend. Each stage records its outcome in the runs table.

Deployment topologies

The same backend image and same SPA bundle support two shipping patterns without forking. The Caddy reverse proxy ships in the all-in-one path; the split path lets the operator host the SPA on a CDN.

What's in the box

Encrypted-at-rest settings

Every credential (AI, TTS, GitHub, storage) is Fernet-encrypted in SQLite under a key derived from DISPATCH_MASTER_KEY. A boot-time canary verifies the key matches a prior session.

Pluggable storage

Single StorageBackend protocol with three implementations — local filesystem, Cloudflare R2, and any S3-compatible API. Swap by editing settings and restarting.

Snapshot pattern

Publish writes an atomic JSON snapshot plus audio. The reader path only ever reads the current snapshot (or an archived one for a specific date) — the synthesis pipeline never blocks readers.

Runtime-editable schedules

Cron expressions live in the schedules table and are editable from /admin/schedules. No redeploy to change cadence.

On-demand addendums

Operators trigger same-day brief updates via POST /api/brief/refresh. A 25-second compressed pipeline produces an addendum attached to the day's filing.

Editorial design system

A hand-set, near-monochrome design language (Inter Tight + JetBrains Mono, signal-red accent, no shadows, square corners). Captured in DESIGN.md.
